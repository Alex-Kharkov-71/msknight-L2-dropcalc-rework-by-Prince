# Drop Calc для L2JMobius (High Five)

[English](README.md) · **Русский**

Веб-справочник и GM-панель для серверов Lineage 2: калькулятор дропа и спойла, справочники предметов, NPC, скиллов,
рецептов, магазинов и спавнов, карты, страницы игроков, кланов и замков, GM-инструменты. Это порт
Michelle Knight's Drop Calc (исходно
PHP 5 + l2jserver) на **PHP 8** и **L2JMobius CT 2.6 High Five**.

> Разрабатывалось и проверялось **только на L2JMobius CT_2.6_HighFive**. Другие ветки Mobius и другие сборки
> (l2jserver, aCis и т. д.) не проверялись, скорее всего потребуют правок.
> **Сначала ставьте на тестовый сервер**: многие GM-инструменты пишут прямо в базу игры.

## Возможности

- Калькулятор дропа / спойла / квестовых предметов с настоящими двухступенчатыми шансами из XML датапака
- Справочники: предметы, NPC (дроп, скиллы, спавн на карте), скиллы, рецепты, магазины, локации, квесты
- Страницы игроков, кланов, замков, клан-холлов, героев, питомцев, рейд-боссов; онлайн; статистика; топы
- GM-инструменты: аккаунты, персонажи, предметы, jail / бан, заметки, журналы, объявления (те, что нужен telnet,
  отключены: в Mobius его нет)
- Несколько игровых серверов с общим логин-сервером; 9 языков интерфейса; 3 скина
- Встроенная установка таблиц и **проверяемые импортёры** XML датапака со статистикой «импортировано / ошибок»
- Публичное зеркало только для чтения: [docs/PUBLIC_MIRROR_RU.md](docs/PUBLIC_MIRROR_RU.md)

## Что нужно

- PHP 8.1+ с расширениями `mysqli`, `xml` (SimpleXML), `gd`, `mbstring`
- MariaDB / MySQL: игровые базы и база логин-сервера
- Папка `data` L2JMobius, доступная веб-серверу (на той же машине или смонтированная копия)
- nginx или Apache

## Установка

1. Скопируйте файлы в корень сайта.
2. `cp config.php.example config.php` (он в `.gitignore`) и заполните `$gameservers` и `$dblog_*`.
   Позиция 6 записи сервера: папка, **внутри которой лежит `data/`**, со слэшем в конце
   (для Mobius `.../dist/game/`). Поля telnet (9–12) оставьте пустыми.
   Новые настройки добавляются в `config.php.example`, переносите их в свой `config.php`.
3. Впишите свой игровой аккаунт в `$install_admins`, например `array("account")`. Откройте сайт, войдите этим
   аккаунтом (пароль из `accounts` логин-сервера) и нажмите **Install tables** в меню (рядом с *Server tools*)
   или откройте `install.php`. Сначала ставится база логина, затем каждый игровой сервер (первый сервер хранит
   ещё и общие настройки интерфейса). Те же скрипты можно выполнить вручную: `sql/install_login_db.sql`,
   `sql/install_game_db.sql`.
   - **Install tables** создаёт недостающее; **Recreate from scratch** удаляет все данные DropCalc в этой базе
     (только таблицы `knight*`, игровые таблицы не трогаются) и требует подтверждения.
   - Пользователю БД из `config.php` нужны права `CREATE` (и `DROP` для пересоздания).
4. Войдите администратором → **Server tools → Import** и по очереди запустите: предметы, NPC (вместе с дропом и
   скиллами NPC), скиллы, рецепты, магазины, спавны, локации, квесты, аккаунты. Каждый импорт заканчивается таблицей
   «импортировано / ошибок». Пока идёт длинный импорт, окно закрывать нельзя.

### Права доступа

Отдельной роли «админ DropCalc» нет: уровень равен `accounts.accessLevel` игрового аккаунта на **логин-сервере**
и учитывается только у **верифицированного** аккаунта (`knightdrop.verified = 1`). Значения по умолчанию после
установки:

| Настройка | По умолчанию | Смысл |
|---|---|---|
| `sec_inc_gmlevel` | 99 | минимальный уровень для GM-страниц |
| `sec_inc_admin` | 100 | минимальный уровень для админ-страниц (100 = полный доступ в стандартном `AccessLevels.xml`) |
| уровни всех GM-функций | 100 | выдача и изъятие предметов и скиллов, кик, объявления, магазины и т. д. |

Если у вас другие уровни, поменяйте их на странице Settings. Уровень GM должен быть ниже уровня админа.
Аккаунты из `$install_admins` всегда имеют полный доступ; когда появятся настоящие админы, очистите список
(см. `sql/make_admin.sql`). Для уже установленной базы:

```sql
UPDATE knightsettings SET sec_inc_gmlevel = 99, sec_inc_admin = 100, sec_giveandtake = 100, sec_takeskill = 100,
  sec_chatto = 100, sec_enchant = 100, adjust_anounce = 100, kick_player = 100, adjust_trust = 100,
  reboot_server = 100, adjust_shop = 100, adjust_drops = 100, sec_adj_notes = 100;
```

Поле `knightdrop.access_level` копия `accounts.accessLevel`: при расхождении вход идёт как гость, поэтому одним
`UPDATE knightdrop` админа не сделать. Первый админ: `sql/make_admin.sql`.

### Полезные настройки

- `db_tokenexp`: таймаут сессии в минутах (30–600, по умолчанию 60)
- `show_online`: лампочки статуса серверов в меню (Off / только до входа / всегда после входа)
- `$status_timeout`, `$logsvr_status_host`: лампочки это обычное TCP-подключение к порту игры / логина, telnet не нужен
- `$telnet_enabled = false`: в L2JMobius нет telnet-консоли, действия через telnet сразу отказывают с понятным сообщением
- `$password_pepper`: только для публичного зеркала, на домашнем сайте пустой

## Что изменилось по сравнению с оригиналом

| Было (старый l2jserver) | Стало (L2JMobius) |
|---|---|
| `mysql_*` | слой совместимости `mysql_compat.php` поверх `mysqli` |
| `npc`, `droplist`, `armor`, `weapon`, `etcitem` в БД игры | XML датапака импортируется в `knightnpc`, `knightdroplist`, `knightweapon`, `knightarmour`, `knightetcitem` |
| `merchant_buylists` | `knightbuylist` (магазины это XML-файлы, только просмотр; режимы списка: со спавном / без спавна / все) |
| `spawnlist` | `knightspawnlist` / `knightspawnzone` (зоны это полигоны, точечные спавны тоже читаются) |
| квесты на Jython | квесты разбираются из `data/scripts/quests/Q*/Q*.java` |
| `class_list`, `skill_trees`, `npcskills` | `knightclass`, `knightskills.levels`, `knightnpcskills` из XML |

Дроп двухступенчатый: шанс группы × относительный шанс предмета; страницы показывают итоговый процент.
Персонажи, кланы, замки, предметы, питомцы, герои, рейд-боссы и др. по-прежнему читаются из **живой** БД игры.

### Чего больше нет

- день/ночь у спавнов, таблица миньонов боссов (в Mobius их нет)
- правка дропа и магазинов (они живут в XML), создание NPC, выдача GM, действия через telnet
- точные точки спавна: на карте рисуется зона (исключение: рейд- и гранд-боссы)
